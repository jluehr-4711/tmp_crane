# KiCad schematic of the adapter board

`adapter.kicad_sch` is generated by `gen_schematic.py` (KiCad 9 format, symbols from the installed
KiCad libraries; the ESP32 DevKit symbol is defined in the script). Schematic only, no PCB.

```
python3 gen_schematic.py                                   # writes adapter.kicad_sch
kicad-cli sch erc adapter.kicad_sch --output erc.txt --severity-all   # expect only: 2 dangling labels (UART_RX, LED), 'Local' lib notice
kicad-cli sch export svg adapter.kicad_sch --output out --no-background-color
```
Open `adapter.kicad_sch` in KiCad (eeschema) to edit by hand; if you do, stop regenerating or port the
change back into the script. The exported drawing lives in `docs/img/adapter-schematic.svg`.
