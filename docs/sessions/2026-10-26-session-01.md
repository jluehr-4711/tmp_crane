## Findings
- Machine: Crane Sports Power X6 Crosstrainer-Ergometer, Royalbeach Art.-Nr. 33821 (2006).
- Supply: AC-AC adapter 26 V~ 2.5 A into a socket at the rear of the frame; rectification happens
  inside the machine (on the brake board 91, assumed).
- Brake: electromagnetic eddy-current brake, coil driven by board (91) in the frame, 16 levels, 400 W max.
- Console link: one cable pair (89 upper / 90 lower) carries power, brake command and speed signal.
  Pinout unknown. Console connectors seen: 2x "PULS" (2-pin), 1x "SEN…" (multi-pin).
- Console PCB: TC5228 / 6706; daughterboard 0526 is (assumed) the hand-pulse amp.
- Hand pulse is explicitly out of scope.

## Owner's answers (interview)
- Console works fine → original signals can be observed.
- Tools: multimeter + ESP32 DevKit only → ESP32 sniffer firmware is needed early.
- ESP32 attaches at the console plug (cable 89); BLE FTMS for the smartphone.
- Owner confirmed: the column top has exactly 3 plugs, 2x PULS (2-pin) and 1x SENSOR (4-pin, red/yellow/green/black). The 4-pin SENSOR plug is the console link. Photo guide reduced to that plug; multimeter procedure added.
- Follow-up: classic ESP32; multimeter is an AstroAI AM33D (no Hz/duty measurement); no separate console manual. Wrote `06-photo-guide.md`.

- Interview part 2: plug swap (not Y-harness), level + computed watts, ESP-IDF, English docs.

- Later the same evening: owner supplied IMG_0629/0630 (console PCB component side + cable entry), copied
  into `material/`. The tube cable lands on a 4-pin header "CONNECTOR" with labels "5V" and "DOUT"; wire
  order green, yellow, red, black. Console has HT7133 3.3 V LDO and HT7033 reset IC. See `02`/`03`.
- Owner read the MCU: Holtek HT46R24 (hardware PWM, no UART) → brake command is most likely PWM on "DOUT".
  No further labels at the 4-pin CONNECTOR besides 5V and DOUT; label positions give **green = 5V, red = DOUT**, yellow/black = GND + speed (order unknown).
